# Backend: MiuWish

## 1. Истории пользователей
- Как пользователь, я хочу создать список желаний, чтобы сохранить подарки на праздник.
- Как друг, я хочу забронировать желание, чтобы никто другой его не купил.
- Как владелец, я не хочу видеть, кто забронировал желание, чтобы сохранить сюрприз.

## 2. Таблицы
- **wishlists**: id (PK), user_id (FK -> users), title
- **wishes**: id (PK), wishlist_id (FK -> wishlists), title, price, url
- **bookings**: id (PK), wish_id (FK -> wishes, unique), user_id (FK -> users)

## 3. API
1. `GET /api/wishlists`: посмотреть все списки. Ответы: 200.
2. `POST /api/wishes/{id}/book`: забронировать. Ответы: 201, 409 (уже занято), 422.
3. `DELETE /api/wishes/{id}/book`: отменить бронь. Ответы: 204, 404.

## 4. Правила
1. Нельзя бронировать свое же желание: иначе 403.
2. Одно желание нельзя забронировать дважды: иначе 409.
